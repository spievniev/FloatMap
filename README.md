# Float Accuracy Heatmap

Heatmap showing difference in accuracy between different types of floats.

![Preview](assets/preview.png)

## Building

Requirements: `clang`

`build.sh` compiles WebAssembly and copies files into `build`.

## Development

Requirement: `entr`, `npx live-server`

`dev.sh` rebuilds on files changes and serves the `build` folder.
